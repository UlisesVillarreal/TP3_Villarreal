# Attack on Titan - Sitio Web

Proyecto desarrollado como trabajo final para la materia PROGRAMACIÓN 3 de la carrera "Tec. Superior en Analisis de Sistemas Informaticos" del Instituto Superior del Milagro

## Descripción

Este sitio web está inspirado en la serie **Attack on Titan** y cuenta con distintas páginas que permiten al usuario iniciar sesión, navegar por información de la serie, completar un formulario interactivo para generar una "tarjeta" y visualizar una galería de imágenes.




## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Páginas del sitio

### Login (`login.html`)
Permite ingresar mediante un usuario y contraseña.

Credenciales válidas:
    - **Usuario:** `admin`
    - **Contraseña:** `password`


### Inicio (`index.html`)
Página principal del sitio con una breve descripción de la serie.

### Información (`info.html`)
Contiene información general sobre Attack on Titan.

### Contacto (`contacto.html`)
Formulario interactivo donde el usuario puede:
    - Completar datos personales.
    - Seleccionar género.
    - Elegir intereses.
    - Validar una cuenta.
    - Generar una tarjeta con la información ingresada.
    - Agregar y eliminar opiniones dinámicamente mediante JavaScript.

### Galería (`galeria.html`)
Página simple desarrollada con Bootstrap que contiene un carrusel de imágenes relacionadas con Attack on Titan.



## Funcionalidades implementadas
    - Navegación entre páginas.
    - Diseño responsive.
    - Validación de formularios.
    - Manipulación del DOM con JavaScript.
    - Eventos mediante `addEventListener()`.
    - Creación dinámica de elementos HTML.
    - Uso de arreglos y recorridos con `forEach()`.
    - Componentes de Bootstrap (Carrusel).



## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `login.html` en cualquier navegador web moderno.

A partir de aqui, primero debera ingresar la cuenta y contraseñas pre-establecidas, luego, si las credenciales son válidas, podra ingresar a las demas ventanas e interactuar libremente con estas.
